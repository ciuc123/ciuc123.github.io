# LinkedIn Posts

This directory contains LinkedIn promotional posts that accompany blog posts.

## Structure

Each LinkedIn post is named to match its corresponding blog post:
- Blog: `_posts/2025-12-16-topic-slug.md`
- LinkedIn: `linkedin_posts/2025-12-16-topic-slug.txt`

## Usage

1. After a Pull Request is created with new content, review both files
2. When ready to publish:
   - Merge the PR to publish the blog post
   - Copy the LinkedIn post content from this directory
   - Paste it to LinkedIn with the full blog URL

## Format

LinkedIn posts are plain text files optimized for LinkedIn's format:
- Compelling hook visible before "See More" (< 200 chars)
- 3-5 key value points with emojis
- Personal insight
- Clear CTA with blog URL
- 3-5 relevant hashtags

## Automation

These files are automatically generated by the GitHub Actions workflow along with their corresponding blog posts.

See `prompts/README.md` for more information about content generation.
