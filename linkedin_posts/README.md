# LinkedIn Posts

This directory contains generated LinkedIn promotional posts for blog articles.

## Format

Each file is named: `YYYY-MM-DD-blog-title-slug-linkedin.txt`

## Usage

1. Content is automatically generated by `.github/workflows/generate-daily-content.yml`
2. Review the generated post
3. Copy the content and paste it to LinkedIn
4. Include the blog URL from the post

## Structure

Each LinkedIn post includes:
- Hook (first 2-3 lines before "See More")
- Value section with key insights
- Personal perspective
- Call-to-action with blog URL
- Relevant hashtags

## Example

```
How much time does your team waste on N+1 queries?

After 13+ years in Laravel development, I've seen this pattern destroy productivity.

Here's what actually works:

[... rest of post content ...]

Full article: https://ciuculescu.com/posts/2025-12-16-laravel-n-plus-one-queries/

#Laravel #PHP #WebDevelopment #DevOps
```
