# Task 060 — Gated Library based on entitlements

## Goal
Library shows content only to entitled users.

## Scope
- Server-side entitlement check for page rendering
- Content list filtered by entitlements
- Non-entitled users see upsell/preview

## Acceptance Criteria
- Entitled users can view full content
- Non-entitled users can only see previews and buy CTA
- No full paid content is shipped to non-entitled clients
